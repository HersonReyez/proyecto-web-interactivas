# Frontend de Anime Store

React + Vite + React Router. Todas las vistas de la aplicación viven aquí; Laravel sirve la API desde `../tienda-anime`.

```powershell
npm ci
npm run dev
```

Abre http://localhost:5173 y mantén el backend en el puerto 8000. Vite reenvía las solicitudes de la API y las cookies de Sanctum.

Consulta [el README principal](../README.md) para la instalación completa, las rutas, el usuario administrador y las pruebas.
